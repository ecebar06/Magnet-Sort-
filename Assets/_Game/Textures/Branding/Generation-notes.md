## Splash prompt

Create a polished portrait splash illustration for a casual mobile word sorting game. Title exactly "WORD SORT", two lines, large readable rounded dimensional refrigerator-magnet lettering, WORD magenta and SORT golden orange, subtle dark purple outlines and soft shadows. Turquoise enamel refrigerator door fills the entire 9:16 vertical composition, softly rounded inset rim and restrained glossy highlights. Below the centered upper-middle logo, a playful compact cluster of chunky cream rounded rectangular word magnets with dark purple text APPLE, BANANA, ORANGE, plus one orange-slice magnet with green leaf. Friendly tactile 2.5D mobile game art, clean and charming, not photorealistic, no characters. Quiet negative space at top and bottom, balanced uncluttered layout, no loading bar, no buttons, no phone frame, no watermarks. Full bleed splash art.

Extract only the WORD SORT logotype from the provided splash image into a standalone transparent PNG logo.
