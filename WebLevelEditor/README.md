# Word Sort Web Level Editor

Open `index.html` in Chrome or Edge. The editor works locally and does not upload project data anywhere.

1. Import `Assets/_Game/Resources/Data/WordLibrary.json`.
2. Set level, move, category and visible-row counts.
3. Add categories and configure transformations.
4. Generate a solvable order and optionally drag words to swap them.
5. Export the level JSON.
6. In Unity use `Tools > Word Game > Import Web Level JSON` and select the exported file.
